■ What this is

A house style for websites, and the rules for building them. A plain-site page is HTML and nothing else: no stylesheet, no style attribute, no CSS from script. It looks the way the browser draws HTML, plus the presentational attributes that every browser still renders thirty years on: bgcolor, <font>, <center>, align, cellpadding.

Why: CSS is where builders go to die, the browser already ships a stylesheet tested on every page ever written, and plain HTML still works in any browser, on any screen, in any decade. It also looks like nothing a language model would make unprompted. This page is built the same way. View its source.

■ Specimens

A working catalogue of everything the browser draws without CSS. Every example is live: edit the source on the left, and the result on the right redraws.

PageWhat is in it
1. Colour bgcolor, <font color>, <mark>, table cells as colour blocks, hr color, tiled wallpaper, the legacy colour parser, document.bgColor
2. Type inline elements, headings, <font size face>, lang, ruby, glyphs as ornament, <pre> diagrams, <xmp>, <nobr>
3. Layout the measure table (a max-width with no CSS), <center> and align, table borders, two-column tables, floating images, indentation, page margins
4. Native <fieldset>, <details> accordions, <meter> colours, dialogs and popovers with no script, form controls, accesskey
5. Museum <marquee>, <frameset>, <plaintext>, <image>, and the dead: <blink>, <spacer>, <basefont>…
6. Night mode dark mode from one meta tag, the system vs fixed palette trade-off, a palette switch through document.bgColor
7. Probe 47 automatic checks of the obsolete features, run in whatever browser you are using

※ 1-7 are access keys: Alt+key in Chrome, Ctrl+Option+key in Safari.

■ The rule

No <style>. No style="". No .css file. No element.style from script. If the browser can't draw it from HTML, the page doesn't need it.
